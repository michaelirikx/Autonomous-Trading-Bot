# Autonomous Trading Bot

Safety-first autonomous crypto trading bot project.

## Shared source of truth

The canonical project state is maintained in `truth/project.json` and the accepted decision history in `truth/decisions.json`. AI-specific instruction files (`AGENTS.md` and `GROK.md`) are bootstrap files only and must not duplicate or override canonical truth.

> Current safety baseline: **LIVE TRADING IS HARD DISABLED.**

The shared-truth protocol, validation workflow, and agent handoff contract are being initialized in this repository.
